## 我做的事情

- 把复杂流程拆成清晰的角色、状态和数据边界。
- 让模型负责理解和整理，把权限、金额、预约和状态变更交给确定性的服务端逻辑。
- 为每个重要结论保留来源、操作记录或可复核的中间结果。
- 用接口测试、浏览器流程和日志确认功能真的跑通。
- 关注超时、重试、并发、权限校验和异常后的恢复，而不是只验证成功路径。
